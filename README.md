# UFO 회의록 위키

이 저장소에는 **화면 코드만** 있습니다. 회의록 데이터는 이 저장소에 없고, 회사 구글 드라이브의 시트에만 있습니다.

- `index.html`, `style.css`, `app.js` : 위키 화면 (깃허브 Pages로 배포)
- 접속: 회사 구글 계정으로 로그인해야 하고, 회의록 시트를 공유받은 사람만 내용을 볼 수 있습니다.
- 위키는 시트를 **읽기만** 합니다(읽기 전용 권한).

## 지켜 주세요
- 회의록 내용, CSV·JSON·엑셀 같은 데이터 파일, 이메일 목록을 이 저장소에 올리지 않습니다. 저장소는 공개입니다.
- 이 저장소는 구글 로그인용 클라이언트 ID와 시트 ID만 담고 있고, 둘 다 공개돼도 되는 값입니다.
- 코드를 바꾸는 계정(저장소 소유자)은 반드시 2단계 인증을 켜 둡니다.
